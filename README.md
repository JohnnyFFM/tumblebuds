# Tumblebuds

A small 3D puzzle game for phones and desktops: guide twenty sleepy buds home through Honeydew Hollow.

**Play:** https://johnnyffm.github.io/tumblebuds/

It can be installed as an app from the browser menu ("Install" / "Add to Home Screen") and then runs fullscreen and offline.

## Development

- `index.html` is the whole game (single source).
- `node build.js` writes the installable version into `docs/`, which GitHub Pages serves.
